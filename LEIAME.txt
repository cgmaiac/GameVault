# GameVault - Loja de Games

Projeto acadêmico de desenvolvimento web: landing page responsiva para uma loja fictícia de jogos.

## Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript

## Funcionalidades
- Catálogo com seis jogos em destaque.
- Layout responsivo para celular, tablet e notebook.
- Menu de navegação adaptável.
- Calculadora de frete com opção de frete grátis para compras a partir de R$ 200,00.
- Formulário de contato com validação dos campos.

## Estrutura do projeto
- index.html: estrutura da página.
- css/style.css: estilos e responsividade.
- js/script.js: funcionalidades JavaScript.
- img/: imagens dos jogos.

## Como executar
Abra o arquivo index.html em um navegador.

Projeto desenvolvido para fins acadêmicos na disciplina de Desenvolvimento Web.
